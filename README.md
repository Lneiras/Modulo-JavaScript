# Gestión de Datos en JavaScript 🚀
## Historia de Usuario: M3S2 - Gestión de datos con objetos, Sets y Maps

Este proyecto consiste en una aplicación de consola en JavaScript desarrollada para consolidar el uso de estructuras de datos avanzadas. El sistema simula la organización y validación de un catálogo de productos empleando **Objetos, Sets y Maps**, además de aplicar métodos modernos de iteración y validaciones de consistencia.

---

## 📋 Características del Proyecto

El código está estructurado en base a 5 tareas principales (**Tasks**):
*   **Gestión de Productos (Objetos):** Almacenamiento de productos con identificadores únicos (`id`), nombres y precios.
*   **Garantía de Unicidad (Sets):** Demostración práctica de cómo un `Set` filtra automáticamente elementos duplicados, junto con operaciones de adición, verificación y eliminación.
*   **Asociación de Datos (Maps):** Vinculación de categorías con productos específicos mediante una estructura clave-valor.
*   **Iteración Eficiente:** Uso de bucles tradicionales y modernos (`for...in`, `for...of`, `forEach()`).
*   **Validación de Datos:** Uso de métodos nativos de objetos (`Object.keys()`, `Object.values()`) para asegurar que no se procesen datos incompletos o erróneos.

---

## 🛠️ Tecnologías y Conceptos Utilizados

*   **JavaScript (ES6+)**
*   **Estructuras de datos:** Arrays, Objects, Set, Map.
*   **Estructuras de control:** `if / else`, `for...of`, `for...in`.
*   **Métodos iterativos y de objetos:** `forEach()`, `Object.keys()`, `Object.values()`.
*   **Buenas prácticas:** Uso estricto de `let` y `const`, nombres de variables descriptivos y comentarios explicativos por secciones.
